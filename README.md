# 电工杯 2026 B题 — 嵌入式社区养老服务站建设与优化

> **奖项：全国三等奖（国三）** | **选题：B题** | **队伍编号：011985B**

基于**马尔可夫人口预测 + 分支定界（BnB）+ 固定点迭代（FPI）+ 成本加成定价**的数学建模解决方案，涵盖设施选址、规模优化、服务定价和政府补贴四大问题。

---

## 项目亮点

- **纯运筹优化问题**：设施选址（Location Allocation） + 容量规划 + 服务定价 —— 工业运筹优化的经典组合
- **混合整数规划求解**：从零实现分支定界算法（BnB）搜索最优建站方案，非调包求解器
- **固定点迭代收敛**：社区-服务站双向选择博弈的均衡求解，带阻尼因子的收敛策略
- **三阶段框架**：人口预测 → 选址优化 → 定价补贴，输出完整商业论证
- **多场景敏感性分析**：支持人口参数、成本系数、预算上限三组参数调优

## 问题与模型

### 问题一：马尔可夫人口预测

基于附件1的现状数据，建立三状态马尔可夫链预测未来5年老人数量和结构：

```
自理 →(p12=0.045)→ 半失能 →(p23=0.10)→ 失能
               ↓ 死亡率 μ=0.05
        新进入者 λ=0.07
```

考虑消费能力约束（月收入×消费上限比例），计算约束后的服务需求。

### 问题二：服务站选址与规模优化

**目标函数**：最大化 `Z = α × 覆盖率 + β × 平均满意度`（α=0.6, β=0.4）

**决策变量**：在10个小区中选择建设服务站，每个站可选不建/小型/中型/大型

**约束**：
- 预算上限 120 万元
- 服务半径 ≤ 1000m（距离满意度分段函数）
- 利用率 ≤ 1.20（允许轻度超载）
- 响应满意度随利用率递减

**求解方法**：
1. **分支定界（BnB）**：按需求降序排列，深度优先搜索，剪枝策略（预算剪枝 + 上界剪枝）
2. **固定点迭代（FPI）**：社区满意度最大化选择服务站 → 站利用率 → 更新响应满意度 → 收敛

### 问题三：服务定价与政府补贴

- 在问题二最优选址方案的基础上
- 以基准价格为锚点，计算保本折扣系数 ρ
- 政府按 2 元/人次补贴（设年补贴上限）
- 利润率控制在 8% 以内

## 快速运行

### 环境要求

```bash
pip install pandas numpy openpyxl
```

### 方式一：分模块运行

```bash
cd src

# 问题一：马尔可夫预测
python Markov.py

# 问题二：选址优化
python BnB-FPI.py

# 问题三：定价补贴（依赖前两步的输出）
python Gsm.py
```

### 方式二：三问集成运行

```bash
cd src
python Four.py              # 默认参数
python Four.py 1            # 加载人口预测参数
python Four.py 2            # 加载成本调整参数
python Four.py 3            # 加载预算调整参数
```
